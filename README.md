# 🌐 Tamil → English Machine Translator

Low-Resource Machine Translation for colloquial Tamil to English,
built using fine-tuned Helsinki-NLP transformer model.

## 🎯 Results
| Metric | Value |
|--------|-------|
| BLEU Score | 27.32 |
| Dataset size | 510 pairs |
| Domains | 5 |
| Training time | ~70 seconds |

## 🚀 Live Demo
👉 https://huggingface.co/spaces/AshGenX/tamil-mt-demo

## 📁 Domains Covered
- 🗣️ Everyday Conversation
- 🏥 Medical
- 🛒 Market / Shopping
- 🎓 School / Education
- 🚌 Transport / Travel

## 🛠️ Tech Stack
Python | HuggingFace Transformers | Helsinki-NLP | Gradio | Google Colab
